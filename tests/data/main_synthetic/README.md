# Main synthetic instance

`tree.nwk` and `constraints.tsv` are the main synthetic instance from
Additional file 2 (`data/main/`), generated by
`scripts/python/00_gen_synthetic_data.py` in Additional file 3: a random binary
tree with 16 leaves (15 internal nodes, labels 1000–1014) and 90 weighted
constraints combining a hidden depth-based chronology with noise.

The copy here is used by `tests/test_original_py3_equivalence.py` so the
cross-version comparison does not depend on the additional-file archive.
